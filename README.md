# vago — loja

Projeto React (Vite) da loja "vago". Backend real no Supabase (produtos, configurações e pedidos).

## Rodar localmente
```
npm install
npm run dev
```

## Build de produção
```
npm run build
```
Gera a pasta `dist/` com os arquivos estáticos prontos para hospedar.

## Deploy
Este projeto está configurado para ser hospedado como site estático (Render, Vercel, Netlify, etc.):
- Build command: `npm run build`
- Publish directory: `dist`
